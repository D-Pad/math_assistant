## What Is a Function?
A **function** is a rule that assigns exactly one output to each input. If 
you think of a function as a machine, you feed it a number (or value), and it 
processes that number according to a specific rule to produce a single 
result.

This is typically written as:
```
f(x) = output
```

Here, `f` is the name of the function, `x` is the input (also called the **
argument**), and `f(x)` is the output.

### Example
```
f(x) = x + 3
```
If `x = 5`, then `f(5) = 5 + 3 = 8`.

## Key Terminology
| Term | Meaning |
|---|---|
| **Domain** | The set of all valid inputs a function can accept |
| **Range** | The set of all possible outputs a function can produce |
| **Independent variable** | The input variable (usually `x`) |
| **Dependent variable** | The output variable (usually `y` or `f(x)`), since it depends on `x` |
| **Codomain** | The set of values a function *could* map to (range is a subset of this) |

## The Vertical Line Test
A graph represents a function only if a vertical line drawn anywhere on the 
graph touches the curve at **no more than one point**. This ensures each 
input has exactly one output — a defining property of functions.

## Common Types of Functions

- **Linear**: `f(x) = mx + b` — graphs as a straight line
- **Quadratic**: `f(x) = ax² + bx + c` — graphs as a parabola
- **Polynomial**: `f(x) = aₙxⁿ + ... + a₁x + a₀` — sums of powers of x
- **Exponential**: `f(x) = a·bˣ` — rapid growth or decay
- **Logarithmic**: `f(x) = log_b(x)` — inverse of exponential functions
- **Trigonometric**: `sin(x)`, `cos(x)`, `tan(x)`, etc. — periodic, wave-like 
  behavior
- **Rational**: `f(x) = p(x)/q(x)` — a ratio of two polynomials
- **Piecewise**: defined by different rules over different intervals of the 
  domain

## Useful Properties

- **Even functions**: `f(-x) = f(x)` — symmetric about the y-axis (e.g., `x²`)
- **Odd functions**: `f(-x) = -f(x)` — symmetric about the origin (e.g., `x³`)
- **Increasing/Decreasing**: describes whether output rises or falls as input 
  increases
- **Composite functions**: `f(g(x))` — applying one function to the output of 
  another
- **Inverse functions**: `f⁻¹(x)` — "undoes" what `f(x)` does, so 
  `f(f⁻¹(x)) = x`
- **Continuity**: a function is continuous if it has no breaks, jumps, or 
  holes in its graph
- **Asymptotes**: lines a graph approaches but never touches (common in 
  rational and exponential functions)

## Why Functions Matter
Functions are the backbone of mathematics and its applications:
- **Physics**: modeling motion, forces, and energy
- **Economics**: supply/demand curves, growth models
- **Computer Science**: algorithms and programming logic
- **Engineering**: signal processing, system design
- **Statistics**: probability distributions

## Quick Notation Cheat Sheet

| Notation | Meaning |
|---|---|
| `f: A → B` | f maps elements from set A to set B |
| `f(x)` | value of f at x |
| `f'(x)` | derivative of f (rate of change) |
| `∫f(x)dx` | integral of f (area under curve) |
| `f⁻¹(x)` | inverse function |
| `(f ∘ g)(x)` | composition, equals f(g(x)) |
