# Math Functions: A Quick Reference
In mathematics, a function is a specific type of relation that assigns 
exactly one output value to each input value from a given set. It is formally 
defined as a rule, expression, or law that establishes a relationship between 
an independent variable (the input, often denoted as $x$) and a dependent 
variable (the output, often denoted as $y$ or $f(x)$)
