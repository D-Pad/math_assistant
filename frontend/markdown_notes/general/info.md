# Intro
When writing notes, use Latex syntax. For example, writing
```
\sqrt[3]{27}
``` 
will display as $\sqrt[3]{27}$ 

For larger equations that
are centered on screen, use double dollar signs:
```
$$
\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```
Which will look like:
$$
\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

## Useful Shortcuts
| Syntax                                    | Output                          |
|-------------------------------------------|---------------------------------|
| `\sqrt{16}`                               | $\sqrt{16}$                     |
| `\sqrt[3]{36}`                            | $\sqrt[3]{16}$                  |
| `x^4`                                     | $x^4$                           |
| `y_2`                                     | $y_2$                           |
| `\frac{x}{y}`                             | $\frac{x}{y}$                   |

A cheat sheet of some Greek symbols and relational symbols can be found
